# 策略演进与复盘日志 (Strategy Changelog)

## [2026-09-21] 针对竞彩让球盘“强队净胜1球”卡盘损耗的机制性优化

### 1. 复盘背景与偏差识别
- **样本依据**：2026-09-20 赛日实盘验证数据。
- **盘路现象**：当日外围亚指有效胜率高达 **78.95%**（15胜1走4负），但竞彩官方让球盘有 **6 场强队精准净胜 1 球**（神户胜利 0-1、利物浦 0-1、巴黎圣日耳曼 1-2、皇家社会 2-3、赫塔菲 1-0、巴拉纳竞技 2-1）。
- **核心问题**：外围平手盘或受让盘全部收米，但竞彩官方让球选项由于净胜球正好落在让球平衡点，全线打出“让球平”，成为竞彩单场与串关断缆的核心损耗源。

### 2. 算法与规则修正思路
1. **预期净胜球（xMargin）胶着区间判定**：
   - 当模型计算的无偏预期净胜球差处于 `|xMargin| ∈ [0.8, 1.3]` 且竞彩盘口为 `让球 (-1 / +1)` 时，系统对竞彩渠道单选“让胜/让负”施加惩罚权重（降权 25%）。
2. **多渠道差异化投注建议（Channel Decoupling）**：
   - **外围渠道**：继续维持亚指与大小球推荐（强队独赢/平手盘不受让平影响）；
   - **竞彩渠道**：
     - 强队优势在 1 球临界点的场次，优先降级为**非让球胜平负**；
     - 若必须选择让球玩法，强制启用“让胜/让负 + 让平”的双选对冲，或直接规避。
3. **低方差组合增强**：
   - 提高弱队受让下盘在串关组合中的优先级（09-20 赛日水晶宫受让 SP 5.00、中国男足受让 SP 3.75 均全额兑现）。
